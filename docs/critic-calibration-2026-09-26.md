# 审片校准与第三轮真实修图

[实际成片对照](../.analysis/critic-calibration-2026-09-26/index.html) · [逐项调整示范 JPEG](../.analysis/critic-calibration-2026-09-26/directed-clean-color/study.jpg)

这轮取得了可展示的影调改善，也确认了当前本地审片模型的限制。示范版由我根据参考逐项调整，草坡暗部更舒展，天空仍有云层起伏；它不是无参考自动流程的交付，天空颜色与作者仍有差距。不能把技术检查通过、双向模型一致或本页示范解释为已经达到作者水平。

## 找到的具体问题与修改

1. **模型混淆同场景照片的对应关系。** 同两张真实导出交换顺序，原多图输入仍两次说“第二张天空更深”。图片哈希、服务日志确认两图均重新编码，没有上下文截断，也不是复用旧图片缓存。交错文字编号仍失败；同一编号画布的这个天空问题双向正确。主线审片及损伤复核已改为单张编号画布，复核交换左右。
2. **审片结论缺少可靠性约束。** 新比较匿名呈现两版、交换左右再比较，只有两次高置信选择同一个文件才有胜者；冲突、低置信和不可用分开记录。相同预览直接跳过模型。每序保留图片身份、画布哈希、完整响应、完成原因和 token 数，截断响应不能参与决策。这检查一致性，不能证明审美正确。
3. **参考模式原来仍在泛泛评价“自然”。** 新参考任务要求每条证据先描述 R 中同区域的真实表现，再比较两版与 R 的关系；缺少参考观察视为不可用。明确参考目标后，本地模型仍未稳定选中更接近作者的候选，旧结果和新结果全部保留，没有按理想答案改写。
4. **差异大小被当成了质量高低。** 多样性搜索失败时，原流程用技术分数、与其他方案的像素距离排列合格候选。新的回退保留最早通过检查的设计，不因为后续版变化更大就替换它；图片、有效配方、Lightroom 照片及审计一起保留。成功找到符合差异目标的方案仍沿用原有流程，未声称所有选片环节已经得到审美比较。
5. **原成片有多层风格处理，模型的全局调整还可能与目标相反。** 自动 B 含蓝色饱和度 −30、蓝色明度 −10、冷色阴影轮和压暗曲线。模型本轮声称恢复地面暗部，却同时增加全局对比并压低黑位；真实导出中暗区 P20 仅保留前版的 83.4%，被检查拒绝。只验证它提出的天空蒙版变化后，地面保留并通过原阈值。另作逐项调整示范，撤掉上述风格叠加、重建基础影调。示范同时改了多项，不能把全部改善归因于某一个滑块。

## 校准结果

使用的运行版本是本机 Ollama 0.33.2、qwen3-vl:32b（Q4_K_M），保留输入与原始响应。不是品牌或模型整体能力排名。

| 试验 | 实际结果 |
|---|---|
| 原多图及交错编号，Kelby 天空深浅 AB/BA | 都只选第二张，顺序失败 |
| 单画布，Kelby 天空深浅 AB/BA | 两次均选实际较深的天空 |
| 纪念碑、登山人物两组留出，8 个区域属性 | 6/8 双向一致且符合独立观察；逐次 13/16 符合 |
| 相同照片 AA，强制经过模型的 4 个属性 | 0/4；模型虚构差异，生产相同预览路径已直接跳过 |
| 取消强制 JSON 的同图 AA 对照 | 仍虚构差异，且不满足所需结构；不能把问题归因于输出格式 |
| 旧参考引导候选，无参考／宽泛参考审美比较 | 都给出平局，但部分区域解释不可靠 |
| 明确 R 观察后的参考比较 | 两组均不足以确定胜者，记录为 uncertain |

## 验证与边界

主线输入修复、完整响应审计和多样性回退修正已安装到应用；三个应用副本的 41 个 Python 文件均与工作区哈希一致。全套 **365 项测试通过**，原生 WebKit 已验证三组对照加载与切换参考。[安装及照片校验记录](../.analysis/critic-calibration-2026-09-26/verification.json)。无参考自动精修仍默认关闭，不会因为本轮示范更好就开启尚未通过实拍验证的自动精修。

另检查了本机已安装的 qwen3.8-27b-uncensored，接口未声明视觉能力，没有作为图片模型调用。尝试下载官方同规模 Instruct 版本作对照，但下载较慢，本轮已停止且未安装，**没有该版本的实验结论**。候选标签与类型来自 [Ollama 官方模型列表](https://ollama.com/library/qwen3-vl/tags)，Thinking/Instruct 的区分可查 [Qwen 官方模型说明](https://huggingface.co/Qwen/Qwen3-VL-32B-Thinking)。

最主要的剩余问题是当前模型对区域光色变化与审美目标的可靠判断；继续增加预设或泛泛要求“更高级”不能证明解决了它。
