# 资料接入与面向普通用户的后期流程

本轮把用户资料整理成能参与方案规划和 Lightroom 执行的方法，默认展示自然精修，用普通中文说明光影和氛围的选择。目标是用户上传后直接判断照片，而不是先选择摄影师、理解 LUT 或调整参数。

## 三份资料的实际接入范围

| 资料 | 核对到的原有状态 | 本轮用途 |
| --- | --- | --- |
| `Downloads/调色素材` | 目录有 50 个 XMP；工程内 16 个预设与原文件 SHA-256 完全一致，另有 129 张练习图的场景统计 | 按当前照片检索合适的练习路线，将适用场景、配色和 HSL 示例送入方案规划；不搬用样片曝光 |
| `Downloads/名人仿色调色.md` | 已简化为 8 套静态配方，新的艺术方向分支会绕过这些配方 | 提炼读图、颜色整理、影调、局部修光与收尾方法；加入可执行起点、按照片调整的约束与分阶段纠错 |
| `Downloads/ph-main` | 工程另有 372 张、68 组、2008–2021 年的旧哈苏索引，不能算作接入此目录的新资料 | 使用哈苏报告中的大气透视、建筑体块、主辅色关系和徕卡报告中的环境叙事、克制配色，指导方法选择 |

这是经验整理和流程实现，没有训练模型。`ph-main` 的全部照片尚未接入视觉检索；当前目录包含哈苏照片及两份报告，缺少 README 中提到的 Leica 图像目录与 analysis 配套数据。本轮读取并提炼报告，不宣称逐张分析了它们所描述的所有作品。

## 已实现的行为

- `finishing_knowledge.py` 提供自然精修、光影叙事、建筑光影、森林层次、柔和暖光、安静纪实六种方法。按照片题材、光线与颜色选择：建筑保留中性色，森林整理绿叶，夜景使用纪实暗调，不统一套冷阴影暖高光。
- 规划输入带上方法来源、适用理由与练习资料提示。`directions-audit.json` 的 `knowledge` 字段完整记录这些内容，可追溯本次真正使用了什么。
- JSON Schema 开放并要求 HSL 对象。模型没有提供的控制继承所选方法，显式零值关闭对应控制；部分配色输出不会清空未提及颜色的处理。解决模型只写“减弱蓝青”却不给颜色调整的问题。
- 检查目标与数值：自然精修不允许过大的中间调位移，柔光目标应抬中间调，暖光方向不重复冷阴影染色；已有主体提亮需求不会在强调主体的 B 中被反向削弱。规划去重加入色轮色相、HSL 和主体／环境局部光线。
- 新增 `color-foundation` 阶段：HSL 和负向饱和度先执行，再修光和塑造影调；色轮仍在影调之后执行。
- 影调质检失败时，从该阶段前的准确 Lightroom 状态尝试 65%、35% 强度，每次重新导出并检查；仍失败才整段撤销。曲线从实际之前的曲线插值，避免多轮调整叠加；审计和最终有效配方保存实际接受的结果。
- 色相启发式只提示蓝青、暖橙区域的变化，不能单独证明天空或肤色损坏，也不用于扣分或自动纠色。已有的可选语义模型在可用、可信时限定天空和人物区域。全图过饱和、裁切和极端亮度检查保持生效。
- 默认先展示 A；卡片解释读取当前方案的实际调整说明，修复仍显示旧预设说明的问题；参数收在“查看调整细节”中。

资料里的布光、拍摄时机、道具和机位用于理解画面，不能在后期里凭空补出。Calibration、精细范围蒙版等执行器尚未支持的控制，也没有包装成已实现效果。

## 验证

后续连接修复合并后，Python 全套 148 项测试通过；前端 JavaScript 语法检查通过。新增回归覆盖：方法按场景选择、结构化颜色输出、柔光目标与曲线一致、色相不同不能被当成相同方案、蓝山与天空识别边界、曲线多轮减弱不叠加、全部失败时准确恢复，以及 API 展示当前方案说明。

本机 Ollama 已实际运行新的方法规划；初次输出暴露了省略 HSL 和重复冷阴影的问题，随后补入方法继承与目标验证。规划审计存于 `.task-cache/study-directions-mountains-final.json`。

最初的 Lightroom 验证在导出未编辑基线前因插件未连接退出。现已修复自动唤醒与连接恢复，并用用户刚才失败的雾中城市照片完成实际调色：作业 `1b65c5ef-b23f-4690-a085-828fb68acb76` 三份成片均已导出，原片保持一致。详见 [连接恢复与实测](lightroom-connection-recovery-2026-09-06.md)。

城市照片影调阶段实际保留 A 65%、C 35% 强度；B 初轮 65%，为增加差别选择第二轮自身方向的版本。A 保留冷灰雾感，B 中间调更沉，C 向柔和暖色移动；AC 差异主要来自色彩，平均色度距离 2.79、亮度差 0.58。建筑与道路的局部层次改善仍有限，不能把此结果表述为审美验收通过。三份结果的视觉模型首轮均评价为 worse，但交换顺序复核没有确认损坏，因此审计如实记录 `damage_confirmed=false`、界面仅报告技术检查；技术得分不作为好看的证据。

原先三种方案过于接近的山景也已完成重新规划及实际导出：作业 `4974d3ef-179a-4212-bb78-bc846686c8f3`，AB / AC / BC 平均 Lab 距离为 7.64 / 4.73 / 6.64。AC 平均色度距离 4.31、亮度差 1.76，颜色方向的差异比旧结果更明显；B 主要增加影调密度。三份曲线均进入实际成片，没有重现旧任务的整段影调撤销。视觉模型对 A 判断 same，对 B/C 首轮判断 worse、但未复核确认损坏；实际看图仍需关注人物面部阴影及前后景关系，不能用差异变大推导美感已达标。原片和输出可在 `.task-cache/recovered-mountain-comparison.html` 对比。
