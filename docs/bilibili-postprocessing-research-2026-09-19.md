# B站摄影后期案例研究：从热门作者的实操中找出 SuperPhoto 的差距

检索与取证日期：2026-09-19。研究范围是照片后期，涵盖风光、城市街拍和人像。选取 5 位有公开人气数据的原创作者，不把粉丝数当作审美结论，也不声称这是一份全站排名。

**最直接的发现：成熟教程会把画面取舍、影调、具体颜色、不同材质和最后复查分别做扎实。当前 SuperPhoto 的主要缺口是区域表达与执行精度；仅增加一种整体色调，难以补上这部分工作。**

## 1. 郭城安：先让画面有视觉中心，再处理颜色

对象是光线斜穿斑马线、行人与影子形成主角的街拍。关键帧可确认以下顺序：约 00:52 处理镜头造成的画面问题；01:46 裁切并保留主角完整的影子；02:39 分析明暗；04:28 用曲线组织反差。05:47 讲具体颜色与整体色调的先后；06:43 发现暗部偏色，06:54 起用混色器针对颜色调整；07:27 收回过量饱和，07:38 再检查反差。

前后画面可见：早期路面和阴影较亮、主角相对不突出；后期暗面收下去，光带、人物和长影子更明确。暖色主要服务于受光区域，暗面没有一同暖成褐色。这里的“干净”同时来自裁切、明暗取舍和收敛局部杂色。[原视频](https://www.bilibili.com/video/BV1tX4y1o7gS/)；[前半关键帧](../.analysis/bilibili-research/frames/BV1tX4y1o7gS-contact1.jpg)；[后半关键帧](../.analysis/bilibili-research/frames/BV1tX4y1o7gS-contact2.jpg)；[净色细节](../.analysis/bilibili-research/frames/BV1tX4y1o7gS-detail1.jpg)。

**适用条件与本项目推论：**原图已有明确光向时，后期应强化已有结构。不要以恢复所有暗处为默认目标；裁切时也要保护影子、倒影等叙事元素，而不只保护人物框。色彩调整后要回看黑白关系，不能默认影调阶段一旦结束就永不修改。

## 2. 青山摄影：同一个人也需要多个不同用途的蒙版

作者章节顺序为 02:33 基础调整、03:59 蒙版、09:33 肤色与颜色、13:00 小技巧、13:58 总结。00:31–02:33 是显示器介绍，不作为修图证据。

关键帧可见皮肤、眼睛、衣服与头发分别处理：皮肤减弱纹理，眼睛提高清晰感，衣服与头发另行处理质感；约 07:53 局部提亮脸部，08:23 用画笔修正覆盖，08:48 已有 5 个蒙版。10:53–11:23 对背景绿、浅绿色收饱和，13:48 同屏对照中面部更明亮，背景仍保留色彩。观察到的是材质与区域分工，不是全图磨皮或全图去色。[原视频](https://www.bilibili.com/video/BV1H5411y71y/)；[蒙版操作](../.analysis/bilibili-research/frames/BV1H5411y71y-detail1.jpg)；[区域净色](../.analysis/bilibili-research/frames/BV1H5411y71y-detail2.jpg)；[最终对照](../.analysis/bilibili-research/frames/BV1H5411y71y-contact4.jpg)。

**适用条件与本项目推论：**需要能分出面部、身体皮肤和衣物，且实际检查蒙版边界。皮肤较柔、眼睛较清、衣服有纹理可以同时成立。对应花卉也应将花瓣与叶片分开；整个人物或整株花作为一个主体蒙版，会把这些相反要求混在一起。

## 3. Thomas看看世界：用明度范围控制调整落在哪里

约 01:40–03:20 演示不同明度范围的黑白蒙版。冰洞案例在 04:10 检查过渡；06:15 将调整约束到选中的亮部，07:05 展示只作用于中间调的曲线。07:35 后换到雪山和黄色花朵，围绕花朵进一步筛选蒙版；12 分钟后处理网页输出。画面可确认局部的光线与纹理被分别组织，不能把其中任意一个曲线参数脱离蒙版照搬。[原视频](https://www.bilibili.com/video/BV1uB4y1V7bL/)；[亮部与中间调](../.analysis/bilibili-research/frames/BV1uB4y1V7bL-contact2.jpg)；[花朵区域筛选](../.analysis/bilibili-research/frames/BV1uB4y1V7bL-detail1.jpg)。

作者另一条[层次感教程，BV1Ht4y1q7m8](https://www.bilibili.com/video/BV1Ht4y1q7m8/)有[官网图文整理](https://chuweimin.com/tutorials/a/photo-depth-3-tips/)：村庄案例通过远处提亮与柔化、中景压暗、边界羽化建立纵深；颜色与空间区域相联系。该文不是要求所有画面都近暗远亮，而是解释前后景需要可读的差异。

**适用条件与本项目推论：**风光与建筑应允许“某个区域里的亮部／暗部／中间调”这种交集，而不只是天空／主体／背景。可沿真实光向做渐进塑光；远景若本来有雾，应保留合理空气感。不能因为整图对比降低，就把空间层次更好的版本判差。

## 4. 摄影师聿铭：仿色先拆解影调，再看通道与具体颜色

开头把不同参考作品与直方图放在一起分析；约 03:27 起调整基础反差；04:56–05:56 操作曲线，06:26 起调整颜色通道，07:56 起进入 HSL。画面从较普通的暖调人像逐步变成有灰感、颜色更克制的版本，同时保留人物和衣物的明暗区分。它说明胶片灰也有明确的反差结构；本次预览不足以准确读取所有曲线坐标。[原视频](https://www.bilibili.com/video/BV1NS4y1x7GK/)；[分析与基础影调](../.analysis/bilibili-research/frames/BV1NS4y1x7GK-contact1.jpg)；[曲线与HSL](../.analysis/bilibili-research/frames/BV1NS4y1x7GK-contact2.jpg)。

**适用条件与本项目推论：**灰感是一种风格选择，不是每张照片的质量目标。必须分别判断黑位抬升、对比塑造和杂色收敛是否必要。参考照片的照明和原始色彩差异很大时，不能把它的整体直方图硬复制到当前照片。

## 5. 冯墨风：全局色调之后，仍需做皮肤光影与小区域修饰

章节确认 00:00 分析、02:52 调色、07:47 中性灰处理皮肤、09:52 嘴唇处理、11:41 再次修改、13:56 总结。关键帧中先并列参考图；约 02:30 裁切，之后调曲线和颜色分级；08:20–09:35 黑白检查视图下处理面部局部明暗，10:00 后单独修饰嘴唇，12:55 又回到整体亮度。13:20–13:45 有同图前后对照，最终暗部更柔，肤色与嘴唇仍能区分。[原视频](https://www.bilibili.com/video/BV1Q34y1V79S/)；[皮肤与嘴唇](../.analysis/bilibili-research/frames/BV1Q34y1V79S-contact3.jpg)；[最终复查](../.analysis/bilibili-research/frames/BV1Q34y1V79S-contact4.jpg)。

**适用条件与本项目推论：**风格化人像的“皮肤干净”不能等同模糊一切。局部明暗不匀和肤色不匀应分别定位；嘴唇、眼睛等小色块不能在统一肤色时一起抹平。这类精修对区域识别、画笔控制和纹理检查的要求，超过目前三类大蒙版的能力。

## 从这些案例提炼的改进顺序

下表是针对本项目的工程建议；不是声称作者使用了这些程序指标。实现能力根据本次读取的工作区源码判断，其他并行任务的后续修改可能改变这一状态。

| 优先级 | 具体改进 | 当前能力与差距 | 验证方式 |
| --- | --- | --- | --- |
| P0 | 每张图先明确视觉焦点、主要光向、应安静的区域与保留颜色 | 已有 intent、subject_box、clutter 框等结构，但需要把这些意图落实成操作 | 缩略图观看焦点是否更明确；再放大检查代价 |
| P0 | HSL、色温与颜色分级服从本图的颜色关系 | 已支持 HSL、RGB 通道曲线、三段颜色分级；固定模板覆盖会破坏本图规划 | 对中性色、皮肤／白花、强调色分别检查，不能用平均饱和度下降代替净色成功 |
| P0 | 影调与调色完成后联合复查 | 已分阶段执行；若影调回退而强染色保留，组合可能失衡 | 增加“颜色变化是否还有配套光影”的复查，必要时一起重新规划 |
| P1 | 把裁切与镜头纠正真正用于主流程 | 已有 crop/optics 与 Lightroom 映射；诊断指出部分主分支未接通裁切 | 检查视觉干扰下降，并保护主体、完整影子和倒影 |
| P1 | 按材质与子区域做多个独立蒙版 | MaskAdjustment 只有 subject/sky/background；EditIntent.masks 上限 3；Lightroom 以 target 为字典键合并 | 人像至少单独检查皮肤、眼睛、衣发；白花至少区分花瓣、叶片、背景 |
| P1 | 支持语义区域与明度／颜色范围相交、渐变和羽化 | 当前原生接口只对三种语义蒙版传局部参数；尚不能表达视频中的亮度交集与人工范围修正 | 展示蒙版覆盖，再看边缘有没有光晕、主体有没有遗漏 |
| P2 | 单独定位去污与皮肤细小明暗修饰 | 本地存在 color_clean/clutter_suppress/defect_heal，但不能据此认为 Lightroom 已执行这些效果 | 用可定位的小区域对照，确认干扰减少且纹理未被抹掉 |

源码依据：[模型与蒙版定义](../src/superphoto/models.py)、[Lightroom参数和蒙版适配](../src/superphoto/lightroom.py)、[本地渲染](../src/superphoto/render.py)。问题现状详见[先前实片诊断](finishing-quality-diagnosis-2026-09-19.md)。

Thomas 的[三条配色规律原文](https://chuweimin.com/tutorials/a/color-grading-3-rules/)也支持这一方向：选主色与点缀色，让不同区域的明度和饱和度有所变化，并使风格与原有光线相配；不能把统一理解成所有区域同色、同亮、同样饱和。[对应 B站视频 BV1Z5411p79M](https://www.bilibili.com/video/BV1Z5411p79M/)。

- 官方预览图只用于核验教学过程。它们含界面、压缩、缩放与中间处理，不可当作 RAW，也不宜拿来计算 SuperPhoto 与作者成片的精确色差。
- 本轮 B站研究负责提炼和核验方法，没有声称已用上述五条视频原片完成同图复刻。真正的同图实验应另选作者明确公开提供的完整原片与成片，并记录许可用途、裁切、尺寸、色彩空间与显示条件。

推荐对标记录不只给一个总分，而是并列列出：画面取舍、视觉焦点、明暗组织、颜色主次、中性色／肤色、纹理与噪声六项。保留每次修改的原始输出，并明确哪些差距来自操作能力缺失，哪些只是审美选择不同。此为本次研究提出的验收设计。
