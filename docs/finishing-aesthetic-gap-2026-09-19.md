# 第二轮实测：为什么仍与作者成片有差距

[打开实际对照页](../.analysis/finishing-gap-2026-09-19/index.html) · [参考引导候选的复评记录](../.analysis/finishing-gap-2026-09-19/reference-guided-reassessment.json)

本轮没有达到“独立自动后期已接近成熟摄影师”的目标。重新跑完整自动流程后，草坡光带与土壤颜色有改善，天空仍偏白。另让模型看作者同图参考后生成参数，得到了更接近参考的实际候选，但本地模型没有可靠地认可它。执行能力、审美规划和验收判断必须分别检验。

## 实际结果

使用 [Scott Kelby 公开练习 CR3](https://lightroomkillertips.com/seven-clicks-to-done-lightroom-before-and-after-step-by-step/)，原始文件不变，所有调整均由 Lightroom 导出；没有合成、换天空或手填作者滑块。

- 完整自动作业：`c3136c17-b19a-43fe-a684-e18231aef876`。重新生成诊断、A/B/C 和配方，实验开启最多两轮成片精修。模型没有看到 Kelby 作者成片。A/C 的微调被判为 `same`，B 未提出剩余问题；没有一轮精修被采用。B 的地面光带更明确，但天空的主要差距依然存在。
- 参考引导实验：模型直接比较自动 B 与作者参考，自行提出继续压天空、提高局部对比等参数。候选位于 `reference-guided/round-0/lightroom/final/source.jpg`，报告第四组直接展示它。
- 固定天空区域的中位 L*：上一轮自动 B **81.66**，本轮自动 B **77.01**，参考引导候选 **57.50**，作者参考 **49.87**。这只辅助描述发白程度，不是审美分数，也不是越低越好。参考截图与导出未精确配准。
- 独立目视审阅认为参考引导候选的天空密度、云天分离明显更接近作者；蓝色纯度、暖云关系和草坡部分阴影仍有差距。

## 找到的具体原因

1. 原有停止条件只要求技术通过且没有确认损伤，不能判断视觉目标是否完成。新增精修实验也证明：当前本地审片模型仍会把偏白天空称为层次清楚，把自然的绿色差异当作需要统一。
2. 初始模型把主色去饱和当作净色。上一轮 B 的蓝色饱和度是 −45；新的提示要求针对当前画面的具体干扰，并明确全局 HSL 会影响所有同色物体，不能假称只整理背景。
3. RAW 的 As Shot 数值可能缺失。旧转换用默认 5500 作为相对色温起点，可能覆盖现场光色。现在只有取得真实色温与色调时才成对调整；否则保留原白平衡并记录原因。插件仅为当前 Develop 目标补读真实值，防止借用别张照片的数据。
4. 已通过的草坡影调，在后续压天空时被全图平均亮度规则重新否决。参考候选的非亮区均值/P20 保留前版的 **95.9%/95.1%**，亮区降至 **57.7%**，没有新增裁切；旧规则仍判 `too_dark`。新检查仅在提供已接受版本、区域保留及裁切条件都满足时将该项改为提示。均匀压暗和继续损失暗部仍被拒绝。

## 保留判断分歧

参考引导候选首次被技术检查拒绝，原始审计没有改写。新的技术复评通过，但本地模型的三图比较仍给出 `worse`，认为候选损失云层过渡；本轮逐图目视判断与它不同。不能把技术通过或某一次模型回答包装成自动审美验收成功。

因此，原自动作业交付不变，参考引导候选单独展示。新增无参考精修保留为实验功能，默认关闭；可以用 `SUPERPHOTO_FINISHING_REVIEW_ENABLED=true` 继续研究。此次完整自动实验启用了该功能，不能与最终默认配置混淆。白平衡、规划提示与相关执行修正已安装到应用。

## 验证

Python 全套 **324 项通过**，包含实际回读缺失、精修失败回退、交付图与配方一致、均匀压暗不能被误放行等回归。Lightroom 真实实验保留原片哈希、阶段导出、有效配方、模型原文及每次取舍；原生 Lua 回读检查也由测试执行。安装副本另做哈希核对。

本轮证据限于这一张 RAW。最主要的剩余工作是让审美判断能可靠发现并选择实际改善，不能继续只增加预设、工具或测试数量来代替看图。
